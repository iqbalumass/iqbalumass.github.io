Teaching

My teaching approach emphasizes active learning, scaffolding, and accessible ways to engage with technical ideas. I use simple examples and visual explanations, followed by implementation and analysis, to help students build confidence and independence.

Examples from My Teaching Work

Exploring the closest-pair problem

For CIS 522, I created an airplane collision detection assignment that gives students a concrete setting for studying divide-and-conquer algorithms. My TA responsibilities included creating assignments and grading assignments, quizzes, and examinations.

Predict, run, and explain

In data structures and algorithms labs, students compare runtime behavior across input sizes and input orderings. They make a prediction, run their programs, and explain how the results connect to operation counts and complexity.

Building data structures from scratch

Stack and queue activities begin with simple examples before students implement the core operations themselves. This approach makes the behavior of each data structure visible before introducing library implementations.
